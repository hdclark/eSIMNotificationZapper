# eSIM Notification Zapper

Android utility to dismiss a specific recurring Samsung SIM-tray warning using an opt-in Accessibility Service. The project is built exclusively through GitHub Actions; no local Android toolchain is required.

> **Status:** Initial repository bootstrap. Application source and CI will be added in the feature branch.

The service cannot intercept a protected system dialog before it appears, and it will not repair SIM hardware. Accessibility access must be explicitly enabled on the device.
